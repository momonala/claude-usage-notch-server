    How the numbers are worked out

    • Weeks start on Monday, in UTC. The first and last weeks can be partial. The heatmap uses the time zone of the machine that ran the report.
    • Each API request is counted once. Claude Code writes several transcript entries for one response and repeats the usage on each, so adding up raw rows roughly doubles every total.
    • Costs use Anthropic API list prices from src/weekly_report.py. A subscription seat isn't billed this way, so read them as the value of the usage, not a bill.
    • Output costs 5× the input rate. Cache writes cost 1.25× input for the 5-minute cache and 2× for the 1-hour cache. Cache reads use each model's own rate.
    • Work is any request whose working directory sits under a path in report_work_paths in pyproject.toml. Everything else counts as personal.
    • Weekly limit use adds up the rises between hourly readings. When the reading drops by 5 points or more before the reset time, that counts as an early reset, so a week can use more than 100%.
